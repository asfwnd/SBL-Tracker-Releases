01

Rest timer starts itself

Enter a set's reps and the rest timer fires automatically. No tapping a separate start button between sets.

02

Offline by default

No signal needed mid-workout. Every set logs to the phone instantly and syncs to the cloud on its own the next time you're online.

03

Carries your last session

Weight and reps prefill from your previous session — per exercise, and per set. Toggle it off any time it's in the way.

04

1RM, estimated as you go

Every logged set feeds an e1RM estimate for that lift, updated live so PRs surface the moment they happen.

05

Media, tied to the set

Attach a photo or clip to the exact set it belongs to — form checks and progress shots stay linked to the numbers.

06

Review from anywhere

Pull up any past workout on any device with just your username — no install, no local backup file required.

07

Updates itself

The app checks for new versions and installs them automatically — no chasing download links for every release.
